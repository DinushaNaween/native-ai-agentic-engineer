## 🎯 Learning Topics

### 1. Linear Algebra for ML
- Scalars, vectors, matrices, tensors
- Matrix multiplication, dot products
- Eigenvalues, eigenvectors (intuition only)
- How embeddings are represented as vectors

### 2. Statistics & Probability
- Distributions (Normal, Bernoulli, Softmax)
- Bayes' theorem and conditional probability
- Expectation, variance, standard deviation
- Why uncertainty matters in AI

### 3. Python for AI
- NumPy — array ops, broadcasting
- Pandas — data manipulation
- Matplotlib / Seaborn — visualization
- Jupyter Notebooks workflow

### 4. Machine Learning Basics
- Supervised vs unsupervised vs reinforcement learning
- Train/val/test splits, overfitting, regularization
- Loss functions, optimizers (SGD, Adam)
- Gradient descent (intuition + implementation)

### 5. Neural Networks 101
- Perceptrons and multilayer networks
- Activation functions (ReLU, sigmoid, tanh)
- Backpropagation (intuition)
- CNNs (image) and RNNs (sequence) — brief overview

### 6. Transformers Architecture (⭐ Critical)
- Attention mechanism — "paying attention" to context
- Self-attention and multi-head attention
- Positional encoding
- Encoder-decoder structure
- BERT (encoder) vs GPT (decoder)
- How tokenization works
